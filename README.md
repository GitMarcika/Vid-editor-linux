# Vid Editor Linux

RHEL 8 / Linux port of Vid Editor.

Target constraints:

- RHEL 8 compatible
- no sudo required on the target machine
- user-space Python environment/runtime
- user-space FFmpeg/FFprobe
- shared project format with the Windows edition

Port source snapshot: `GitMarcika/Vid-editor@be9312f`.

Development work is staged; see `docs/PORT_PLAN.md`.
